# Third-party content

The assets below were made by other people. They are **not** covered by this
mod's APL-SA license and keep their own licenses, listed per asset. CC BY
licenses allow reuse for any purpose, commercial use included, as long as the
creator is credited; CC0 assets need no credit, but we give it anyway. The
licensors give no warranty; see each license for details.

Each addon is published on its own, so the credits are grouped by the addon
that ships the files. Source files under `assets/` are only in this repository.
Addons not listed here (Core, Vegetation, Dev, the ELifeRPG meta-pack) ship no
third-party assets.

## When you publish the mod

Players get the mod from the Workshop, not from this repository. So the
credits have to be on the Workshop page of every addon that ships the asset.
Put the matching block in that addon's description. The ELifeRPG meta-pack
ships no assets itself; its page can point to the addon pages.
